# Process Document Update Checklist

Purpose: Provide a consistent template and checklist for updates to process documentation.

## Metadata
- Document:
- Author:
- Date:
- Related issue/PR:

## Summary of change
- Short description of what changed and why.

## Stakeholders consulted
- List of people or teams consulted for the update.

## Acceptance criteria
- [ ] Content aligns with existing process docs
- [ ] Update improves clarity or closes a documented gap
- [ ] Examples or templates included where applicable
- [ ] Reviewed by relevant stakeholders (list reviewers)
- [ ] Published to docs/ and linked in project README (or .copilot/)

## Suggested sections to include in role/persona entries
- Role Summary
- Responsibilities
- Interactions (who to work with)
- When to involve
- Key deliverables

## Post-merge steps
- Notify stakeholders / send announcement
- Add to onboarding checklist if appropriate
- Link PR and issue in project board
